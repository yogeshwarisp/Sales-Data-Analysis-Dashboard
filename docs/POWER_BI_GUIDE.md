# Power BI Dashboard Guide

Build the dashboard in **Power BI Desktop** (free, Windows). Run the Python pipeline first so that
`data/cleaned_sales_data.csv` exists.

> The `.pbix` file cannot be generated by code. You build it by following this guide, then save it as
> `reports/Sales_Analysis_Dashboard.pbix`. Everything below uses the exact column names in the cleaned CSV.

---

## Step 1: Load the data

1. Open Power BI Desktop → **Home → Get data → Text/CSV**.
2. Select `data/cleaned_sales_data.csv` → **Transform Data** (not Load).
3. In Power Query, check each column type (header icon, or **Transform → Data Type**):

| Column | Type |
|---|---|
| order_date, ship_date | Date |
| sales, profit, discount | Decimal number |
| quantity, order_year, order_month, ship_days, discount_band_order, row_id | Whole number |
| order_id, product_name, category, sub_category, region, state, order_year_month, order_quarter, order_month_name, discount_band, postal_code | Text |

4. **Home → Close & Apply**.
5. Rename the query/table to `cleaned_sales_data` if it is not already named that (right-click the table in the Data pane → Rename). **All DAX below uses this name.**

**Stop summing the wrong fields:** in the Data pane, select `discount`, `order_year`, `order_month`, `ship_days`, `row_id`, `discount_band_order` → **Column tools → Summarization → Don't summarize**.

**Turn off Auto date/time** (we build our own date table): **File → Options → Current File → Data Load → untick "Auto date/time"**.

---

## Step 2: Create the Date table

Go to **Table view → Table tools → New table** and paste:

```DAX
Date =
ADDCOLUMNS (
    CALENDAR (
        DATE ( YEAR ( MIN ( cleaned_sales_data[order_date] ) ), 1, 1 ),
        DATE ( YEAR ( MAX ( cleaned_sales_data[order_date] ) ), 12, 31 )
    ),
    "Year", YEAR ( [Date] ),
    "Month Number", MONTH ( [Date] ),
    "Month Name", FORMAT ( [Date], "MMM" ),
    "Month Year", FORMAT ( [Date], "MMM yyyy" ),
    "Month Year Sort", YEAR ( [Date] ) * 100 + MONTH ( [Date] )
)
```

Then:

1. **Mark as date table:** select the `Date` table → **Table tools → Mark as date table** → choose the `Date` column.
2. **Sort columns** (this fixes alphabetical month order):
   - Select `Month Name` → **Column tools → Sort by column → Month Number**
   - Select `Month Year` → **Sort by column → Month Year Sort**
3. **Create the relationship:** **Model view** → drag `Date[Date]` onto `cleaned_sales_data[order_date]`.
   It must be **Many-to-one (cleaned_sales_data to Date), single direction**.
4. Select `Year`, `Month Number`, `Month Year Sort` → **Don't summarize**.

---

## Step 3: Create the DAX measures

Select the `cleaned_sales_data` table in the Data pane → **Home → New measure** (or **Table tools → New measure**). Create each measure one at a time.

```DAX
Total Sales = SUM ( cleaned_sales_data[sales] )
```
```DAX
Total Profit = SUM ( cleaned_sales_data[profit] )
```
```DAX
Total Orders = DISTINCTCOUNT ( cleaned_sales_data[order_id] )
```
```DAX
Total Quantity = SUM ( cleaned_sales_data[quantity] )
```
```DAX
Profit Margin % = DIVIDE ( [Total Profit], [Total Sales], 0 )
```
```DAX
Avg Order Value = DIVIDE ( [Total Sales], [Total Orders], 0 )
```
```DAX
Avg Discount % = AVERAGE ( cleaned_sales_data[discount] )
```
```DAX
Sales Last Year =
CALCULATE ( [Total Sales], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )
```
```DAX
Sales YoY % =
DIVIDE ( [Total Sales] - [Sales Last Year], [Sales Last Year] )
```
```DAX
Sales Previous Month =
CALCULATE ( [Total Sales], DATEADD ( 'Date'[Date], -1, MONTH ) )
```
```DAX
Sales MoM % =
DIVIDE ( [Total Sales] - [Sales Previous Month], [Sales Previous Month] )
```

**Format each measure** (select it → **Measure tools** ribbon):

| Measure | Format | Decimals |
|---|---|---|
| Total Sales, Total Profit, Avg Order Value | Currency ($) | 0 (cards) or 2 |
| Total Orders, Total Quantity | Whole number, comma separator | 0 |
| Profit Margin %, Avg Discount %, YoY %, MoM % | Percentage | 1–2 |

> **Why `Total Orders` uses DISTINCTCOUNT:** one order can contain several rows (line items). Counting rows would overstate orders.
> **Why Profit Margin % is a measure, not a column:** a margin must be recalculated as total profit ÷ total sales for whatever is filtered. Averaging row-level margins gives a wrong answer.

## Step 4: Apply the theme and set up the canvas

1. **View → Themes → Browse for themes** → select `powerbi/corporate_theme.json`.
2. Page size: **Format page → Canvas settings → Type: 16:9** (1280 × 720).
3. Set the page background: **Format page → Canvas background → colour `#F4F6F8`, transparency 0%**.

Use **Format → Position** (select visual → Format pane → General → Properties → Position/Size) to enter exact values.

| Row 1 | Monthly Sales Trend (line) | 20 | 235 | 500 | 230 |
| Row 1 | Sales by Region (bar) | 530 | 235 | 360 | 230 |

## Step 6: Build the visuals

### KPI cards (5)
Insert the **Card** visual five times. Drag one measure into each:
`Total Sales`, `Total Profit`, `Total Orders`, `Total Quantity`, `Profit Margin %`.
Format: **Callout value** font Segoe UI Semibold 24–28, colour `#1F4E79`. Category label on, font 10, grey. Add a thin border.

### Monthly Sales Trend (Line chart)
- **X-axis:** `Date[Month Year]` (sorted by `Month Year Sort`, so the order is chronological)
- **Y-axis:** `Total Sales`
- Format: markers on, line colour `#1F4E79`, gridlines light grey, title "Monthly Sales Trend".
- If the labels are crowded, set **X-axis → Type: Categorical** and rotate labels 45° (**X-axis → Values → Angle**).

### Sales by Region (Bar chart)
- Use **Clustered bar chart**. **Y-axis:** `region`. **X-axis:** `Total Sales`.
- **Visual → Sort axis → Total Sales → descending.** Turn **Data labels** on.

### Sales by Category (Donut chart)
- **Legend:** `category`. **Values:** `Total Sales`.
- Format: **Detail labels** show *Category, percent of total*; inner radius about 60%; legend at bottom.

### Top 10 Products (Horizontal bar)
- **Clustered bar chart.** **Y-axis:** `product_name`. **X-axis:** `Total Sales`.
- Open the **Filters pane** → `product_name` → **Filter type: Top N** → Show items **Top 10** → By value `Total Sales` → **Apply filter**.
- Sort descending by `Total Sales`. Names are long, so give this visual enough width.

### Profit by Category (Column chart)
- **Clustered column chart.** **X-axis:** `category`. **Y-axis:** `Total Profit`.
- Conditional colour for losses: **Columns → Colors → fx** → *Format style: Rules* → value < 0 → red `#C0392B`, otherwise `#2E8B57`.

### Sales and Profit Comparison (Line and clustered column chart)
- **X-axis:** `sub_category`. **Column y-axis:** `Total Sales`, `Total Profit`. **Line y-axis:** `Profit Margin %`.
- This shows volume and profitability together: a sub-category with high sales but a low or negative margin stands out immediately.
- Turn on **Secondary Y-axis** formatting as a percentage.

## Step 7: Slicers

Insert three **Slicer** visuals:

| Slicer | Field | Style |
|---|---|---|
| Year | `Date[Year]` | Dropdown (or Tile/Between) |
| Region | `cleaned_sales_data[region]` | Dropdown |
| Category | `cleaned_sales_data[category]` | Dropdown |

Format: **Slicer settings → Style → Dropdown**; turn **Selection → Multi-select with Ctrl** off if you want checkboxes to allow multiple picks;
enable **Show "Select all" option**. Test: pick a Year and Region, and watch every visual update.

---

## Step 8: Validate against Python and SQL (do not skip)

With **no slicers selected**, compare the five KPI cards to your own results:

| Value | Python | SQL | Power BI |
|---|---|---|---|
| Total Sales | `reports/kpi_summary.csv` → `total_sales` | `reports/sql_results/01_overall_kpis.csv` | Card |
| Total Profit | `total_profit` | same file | Card |
| Total Orders | `total_orders` | same file | Card |
| Total Quantity | `total_quantity` | same file | Card |
| Profit Margin % | `profit_margin_pct` | same file | Card |

They should agree (allow for rounding in the last decimal). Then test one slice: set Region = a single region and compare to
`reports/regional_analysis.csv`, and Category = one category and compare to `reports/category_analysis.csv`.

**If a number differs:**
- Orders too high → `Total Orders` must use `DISTINCTCOUNT`, not `COUNT`.
- Sales/Profit differ → check that you loaded `cleaned_sales_data.csv` (not the raw file).
- Months in the wrong order → check Sort by column (Step 2).
- Totals change with no slicer → check for a stray visual-level filter.

---

## Step 9: Save, screenshot, publish

1. **File → Save as →** `reports/Sales_Analysis_Dashboard.pbix`.
2. Take a screenshot of the finished page (**Windows + Shift + S**), save it as `images/dashboard_overview.png`. This is what the README displays.
3. **Publishing (optional):** **Home → Publish** requires signing in with a **work or school** Microsoft account (personal Gmail/Outlook accounts are usually not accepted).
   If you have no such account, skip publishing and use the screenshot plus the `.pbix` file.
   Avoid **Publish to web** unless you are happy for the data to be public to anyone with the link.
4. Never upload files containing passwords or keys. This project uses none.

---

## Where each Power BI skill shows up in interviews
- **Data model:** a star-like model with a date dimension and a one-to-many relationship.
- **DAX:** measures vs columns, `DIVIDE`, `DISTINCTCOUNT`, time intelligence (`SAMEPERIODLASTYEAR`, `DATEADD`).
- **Validation:** reconciling the dashboard with independent Python and SQL calculations.
